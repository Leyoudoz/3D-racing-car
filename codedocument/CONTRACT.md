# S0 契约（开发前声明）

## 输入
- 用户指令：森林风格赛道、跑车（非拉力车）、机器人对手、21 条赛道、全贴图、极高画质、阴影、音效、轻音乐、轻量 APK。
- 环境事实（实测）：ADB 设备 nabu / Android 11 API30 / x86_64 / GLES 3.0；本机 Android SDK platform-34、build-tools 34.0.0、aapt2、d8、apksigner、zipalign、JDK17/21/25；无 NDK、无 Gradle、无引擎。

## 输出
- 可安装 APK：versions/ForestRacer-v01.01.00.00.apk
- 安装到 ADB 127.0.0.1:5555 并实际启动验证。
- 源码 git/forest-racer/，文档 codedocument/，日志 codedocument/更新日志.log。

## 单位与返回类型
- 3D 坐标：米（m）；速度：米/秒（m/s）；时间：秒（s）；角度：弧度（rad）。
- 游戏状态机枚举：MENU / RACE / RESULT；Java 方法返回 boolean/int/float/void，不吞异常。

## 边界
- 赛道数固定 21，索引 0..20；非法索引拒绝并记 WARN。
- 赛道生成使用可复现伪随机（固定种子 = 赛道索引），同一赛道每次形状一致。
- 车辆数：玩家 1 + 机器人 5；机器人按赛道中心线循迹，简单避让。
- 纹理分辨率 1K；声道：背景轻音乐 1 路，引擎/碰撞音效按需。
- 最低 API 24，目标 API 34；x86_64 设备实测，ARM 设备兼容（纯 Java，无 native so）。

## 错误类型
- 素材缺失：启动时显示错误页而非崩溃；资源加载异常捕获并记日志。
- 输入越界：赛道索引、玩家数量钳制并记 WARN。

## 技术选型与理由
- 引擎：不用 Unity/Godot/Unreal（本机无引擎，且体积大）。采用纯 Java + OpenGL ES 3.0 自研渲染，依赖零第三方库，包体最小，满足轻量要求。
- 语言：Java（Android 原生，用户要 APK；C++ 需 NDK，本机无，故用 Java，理由充分）。
- 贴图：Poly Haven CC0 1K JPG（沥青、草地、岩石、树皮），本地打包进 assets，运行时通过 BitmapFactory 解码上传 GLES 纹理。
- 音频：本地生成 OGG/WAV（轻音乐与引擎/碰撞音效），SoundPool + MediaPlayer 播放。
- 阴影：GLES 3.0 阴影映射（FBO + 深度纹理），车辆与树木投影到赛道。
- 模型：程序化生成跑车网格（低多边形但带法线/贴图），机器人对手同模型不同颜色。树木用交叉面片 + 树皮/树叶贴图。

## 安全评估
- 本次不联网、不读用户数据、不写外部存储、不申请权限；无注入/越权/明文传输面。
- 资源耗尽防护：纹理固定 1K、几何固定上限、帧循环固定步长、粒子数量上限。
- 不在范围：多人联机、账号系统、支付、外部存储写入。
